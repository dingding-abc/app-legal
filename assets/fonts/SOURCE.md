# Inter

InterVariable.woff2 is the unmodified Inter 4.1 regular variable font, downloaded on 2026-09-27 from the official distribution:

- Font: https://rsms.me/inter/font-files/InterVariable.woff2?v=4.1
- Versioned license: https://raw.githubusercontent.com/rsms/inter/v4.1/LICENSE.txt
- Upstream: https://rsms.me/inter/

The SIL Open Font License is included in `Inter-LICENSE.txt`. Serve the font locally; no remote stylesheet is required. Inter does not supply Chinese or Japanese glyphs; the site uses language-appropriate system fallbacks for those characters.
