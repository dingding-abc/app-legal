Swiftally

プライバシーポリシー

最終更新日：2026年11月28日

Swiftally は個人開発者が提供します。書き出しやバックアップを行わない限り、帳簿、ToDo、圧縮添付写真は端末内に保持されます。

プライバシーやサポートに関するお問い合わせ：daniel.ding117@gmail.com。

帳簿、ToDo、圧縮写真添付

帳簿、明細、金額、カテゴリ、割り勘、立替・精算・貸借 ToDo、メモ、カスタム通貨、ショートカット、設定、および複数枚の添付写真（1件につき最大9枚の圧縮 JPEG）は端末内の SQLite データベースとアプリ領域に保存されます。開発者アカウントは不要で、広告や追跡分析 SDK は組み込んでいません。撮影時にカメラ権限、選択時に写真ライブラリ権限を求めます。設定 → 環境設定の「写真をアプリ内に保存」は初期設定でオンになっており、圧縮コピーをアプリ内サンドボックスに独立保存するため、写真アプリから元画像を削除しても閲覧できます。オフ時はローカル画像 URI を参照します。

任意の AI 音声・写真認識

基本の手動記帳、ToDo 管理、写真添付は無料で AI 契約は不要です。任意の AI 音声記帳（立替・精算・貸出・借入の相手先自動抽出を含む）および AI 写真・レシート認識には、有効な Apple AI Pro サブスクリプションまたはトライアル、通信接続、マイク・カメラ・写真権限が必要です。実行時は今回の音声データ／テキストまたは選択した圧縮レシート画像と、有効なカテゴリ名・帳簿名・通貨一覧・端末日時・IANA タイムゾーンのみを HTTPS で Serverless AI ゲートウェイ（中国本土は Alibaba Cloud Function Compute 上の Bailian／Qwen／DeepSeek、海外は Google Cloud Run 上の Gemini およびフォールバックモデル）へ送信します。クライアントに API キーは保持せず、既存の帳簿履歴や無関係な写真は送信しません。

処理と保持

ゲートウェイは AI モデル呼び出し前に利用権を確認し、音声、認識テキスト、レシート画像、購入証明の永続データベースを作成しません。入力は記帳下書きと ToDo 候補の生成にのみ使用されます。端末上の一時録音ファイルは完了またはキャンセル時に削除されます。クラウド基盤が運用ログを保持する場合があり、Apple、Alibaba Cloud、Google Cloud には各社の保持ポリシーが適用されます。AI 下書きは確認・保存するまで正式記録にならず、編集・取り消し・削除が可能です。

iCloud、書き出し、為替レート

任意の iCloud バックアップは、添付写真を含む手動の帳簿スナップショットを Apple Account の CloudKit プライベートデータベースに保存します。手動スナップショットであり自動同期ではありません。CSV レポートは選択した共有先にのみ出力され、帳簿の復元には使えません。オンライン為替更新は公開レートサービスに通貨コードのみを送信し、帳簿記録は送りません。

購入と確認

AI Pro 自動更新サブスクリプション（月額・年額プラン）および任意のチップ決済は Apple の StoreKit が処理します。アプリは検証済み取引、現地価格、利用権状態のみを読み取り、カード情報は受け取りません。任意のチップは AI 権限と別です。iOS、TestFlight、クラウド基盤が各設定・ポリシーに従い診断情報を生成する場合があります。

保持、選択、お問い合わせ

端末内データは編集または削除するまで保持されます。アプリ内で任意の明細、ToDo、写真、カテゴリ、帳簿、カスタム通貨、ショートカットを閲覧・ズーム・追加・編集・削除でき、削除時はサンドボックス内の孤立写真も自動整理されます。写真アプリ、共有 CSV、過去のスナップショットは個別に管理してください。アプリ削除は Apple 端末バックアップの挙動に従い端末データを消去しますが契約は解約されません。メール内容は問い合わせ対応と法的義務に必要な期間のみ保持します。変更は上部日付に反映します。
