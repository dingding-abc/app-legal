Kinsanote

プライバシーポリシー

最終更新日：2026年11月28日

Kinsanote は個人開発者が提供します。ご家族のプロフィール、医療ノート、検査記録および検査結果の原本写真は、ご自身で個人の iCloud 同期や Apple ファミリー共有を有効にしない限り端末内に保持されます。

プライバシーやサポートに関するお問い合わせ：daniel.ding117@gmail.com。

医療記録と無劣化の検査原本写真

家族プロフィール、医療ノート、検査記録、再検査リマインダー、設定、複数ページの検査写真（高画質保存）は端末内の SQLite データベースとサンドボックス領域に保存されます。開発者アカウントは不要で、広告や追跡分析 SDK は組み込んでいません。スキャン・撮影時にカメラ権限、選択・保存時に写真ライブラリ権限、リマインダー設定時に通知権限を求めます。記録や写真を削除・差し替えすると、参照されなくなったサンドボックス内の画像ファイルは自動的に削除されます。

任意の AI 検査結果読み取り

手動記録、複数ページの閲覧、ピンチズーム確認、塗りつぶしマスキング、すべての編集・削除は AI 契約なしで無料利用できます。任意の AI 読み取りには、初回プライバシー同意（設定画面でいつでも撤回可能）、通信接続、および有効な Kinsanote AI Pro サブスクリプションまたはトライアルが必要です。実行時は選択した検査画像（事前にマスキング可能）と端末の現地日時・IANA タイムゾーンのみを HTTPS で Serverless AI ゲートウェイ（中国本土は Alibaba Cloud Function Compute 上の Qwen/DeepSeek、海外は Google Cloud Run 上の Gemini/OpenAI/DeepSeek フォールバック）へ送信します。アプリに API キーは保存せず、他の家族や無関係な記録は送信しません。

処理と下書き確認

ゲートウェイは AI モデル呼び出し前に利用権を確認し、送信画像や購入証明の永続データベースを作成しません。入力は構造化下書きを返すためにのみ処理されます。クラウド基盤が運用ログを保持する場合があり、Apple、Alibaba Cloud、Google Cloud の各社ポリシーが適用されます。AI の読み取り結果は編集可能な下書きとして表示され、原本と照合して確認したうえで保存します。

任意の iCloud と Apple ファミリー共有

iOS で有効にすると、Apple Account に紐づく CloudKit プライベートコンテナに保存され、開発者側の医療サーバーは使用しません。ファミリー共有はノート単位（プライベート／ファミリー共有）で制御され、共有が解除またはプライベートへ変更されると端末内の未承認共有コピーは即座に隔離・消去されます。

購入と確認

任意の買い切り型「ファミリー永久版」および自動更新の Kinsanote AI Pro サブスクリプション（月額・四半期・年額、ファミリー共有および対象時の1か月無料トライアル対応）は Apple の StoreKit が処理します。アプリは検証済み取引と現地価格・利用権のみを読み取り、カード情報は受け取りません。

保持、選択および非医療診断の注記

端末内データは編集・削除するまで保持され、アプリ内でメンバー、ノート、検査記録、リマインダー、個別の写真をいつでも確認・ズーム・追加・編集・削除できます。アプリ削除は Apple 端末バックアップの挙動に従い端末データを消去しますが契約は解約されません。本アプリは個人・家族の健康記録整理を目的とし、医学的診断や治療助言を行いません。メールは問い合わせ回答にのみ使用します。
