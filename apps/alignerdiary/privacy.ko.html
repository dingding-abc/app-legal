정보와 사용 목적

계획, 착용 기록, 목표, 기분, 메모, 진료 일정, 알림, 사진과 설정을 기록, 통계, 비교 및 알림 제공에 사용합니다. 개발자 계정이나 개발자 서버로 일기를 전송하는 기능은 없으며 광고, 앱 간 추적, 행동 분석도 없습니다.

사진, 권한과 위젯

카메라와 알림 권한은 선택 사항이며 기존 사진은 Apple 선택기로 고릅니다. 앱은 위치를 포함한 불필요한 EXIF를 제거한 가공 사본을 보관하고 사진 앱의 원본은 변경하지 않습니다. 별도 JPEG 저장에는 추가 전용 권한이 필요하며 자동 저장은 기본적으로 꺼져 있습니다. 저장 이미지에는 메모나 장치 번호가 없고 가져온 사진은 자동으로 다시 저장하지 않습니다. 위젯은 확인 시간과 체험 만료를 포함한 제한적인 착용, 장치, 일정 및 접근 정보만 사용하며 일기 메모, 사진, 원본 영수증이나 카드 정보는 포함하지 않습니다.

선택적 백업

내보내기에는 일기, 사진과 설정이 포함되며 저장 위치는 직접 선택합니다. 앱은 추가 비밀번호나 암호화를 제공하지 않습니다. 선택적 iCloud 백업은 기본적으로 꺼져 있고 Apple 계정의 개인 CloudKit에 스냅샷을 저장합니다. 개발자는 개발자 포털에서 내용을 읽을 수 없습니다. 양방향 동기화가 아니며 앱이 전면에 있을 때 백업을 시도하지만 완료를 보장하지 않습니다. 기기에 저장된 iCloud 계정 식별자로 계정 변경을 감지합니다. 계정 변경, 백업 끄기, 복원, 복원 취소 또는 이 앱의 모든 로컬 데이터 삭제 시 이후 업로드가 중단되지만 진행 중인 업로드는 완료될 수 있고 기존 사본은 자동 삭제되지 않습니다. Apple 개인정보 처리방침을 참조하세요.

복원은 현재 데이터를 병합하지 않고 대체합니다. 복구 지점이 유지되지만 복원 취소 시 복원 후 수정 사항은 버려집니다. 복원, 복원 취소 또는 이 앱의 모든 로컬 데이터 삭제 후 사진 자동 저장은 꺼집니다.

구매 확인

Apple StoreKit은 체험과 구매 거래 및 원래 앱 정보를 확인합니다. 개발자는 결제를 위해 일기나 카드 정보를 받지 않습니다. 시간 확인 정보와 체험 안내를 닫은 선택은 키체인에 저장되며 앱 삭제 후 남을 수 있고 일기 백업에는 포함되지 않습니다. 데이터 삭제로 체험이 초기화되거나 구매가 취소되지는 않습니다.

보관과 선택

로컬 데이터는 삭제, 대체 또는 전체 삭제 전까지 보관됩니다. 체험 만료 후에도 보기, 내보내기, 선택한 계획 삭제 및 모든 로컬 데이터 삭제가 가능합니다. 사진은 실행 취소 기록, 복구 지점 또는 백업에 남을 수 있습니다. 전체 삭제는 복구 지점을 삭제하고 설정과 사진 및 클라우드 자동 백업을 초기화합니다. 로컬 삭제로 사진 앱 사본, 내보낸 파일, iCloud 또는 기기 백업, Apple 구매나 키체인 정보는 삭제되지 않으므로 각각 관리해야 합니다. 권한을 거부하거나 철회하고 선택 기능을 끌 수 있으며 개발자는 기기나 개인 클라우드 데이터를 원격으로 삭제할 수 없습니다.
